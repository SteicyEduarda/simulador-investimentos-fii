# Diretrizes de Contribuição

Obrigada por se interessar em contribuir! Este é um simulador educacional.

## 📝 Como Contribuir

### Reportar Problemas ou Sugestões
1. Vá para **Issues**
2. Clique em **New Issue**
3. Escolha o tipo:
   - 🐛 **Bug** — Erro na planilha
   - 📊 **Melhoria** — Nova funcionalidade
   - 📝 **Documentação** — Melhorar guias

### Sugestões Bem-Vindas
- Novas métricas financeiras
- Cenários adicionais
- Melhor visualização
- Comparação com outros investimentos
- Tradução para outras línguas
