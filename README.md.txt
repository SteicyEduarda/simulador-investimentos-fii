# 📊 Simulador de Investimentos em Fundos Imobiliários

## 📌 Sobre o Projeto

Este projeto consiste na criação de uma ferramenta simples em Excel para simular investimentos em Fundos Imobiliários (FIIs).

A planilha permite calcular e visualizar informações importantes, como o valor total investido, o patrimônio acumulado e uma estimativa dos dividendos mensais.

O objetivo é ajudar investidores iniciantes a compreender melhor o impacto dos investimentos ao longo do tempo.

## 🎯 Objetivo

Criar uma solução prática e acessível para simular investimentos em Fundos Imobiliários utilizando o Microsoft Excel.

## 🛠️ Ferramentas Utilizadas

* Microsoft Excel
* Git
* GitHub
* Markdown

## 📈 Funcionalidades

A planilha permite:

* 💰 Simular valores de investimento;
* 📊 Visualizar o valor total investido;
* 🏦 Acompanhar o patrimônio acumulado;
* 💵 Estimar os dividendos mensais;
* 📅 Analisar diferentes cenários de investimento.

## ▶️ Como Utilizar

1. Baixe o arquivo da planilha disponível neste repositório.
2. Abra o arquivo utilizando o Microsoft Excel.
3. Preencha os campos necessários para realizar a simulação.
4. Analise os resultados gerados.
5. Altere os valores para testar diferentes cenários.

Este projeto possui finalidade educacional. Os resultados apresentados são apenas simulações e não representam recomendação de investimento ou garantia de rentabilidade.
